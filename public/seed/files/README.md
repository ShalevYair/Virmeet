# קבצי רקע (seed)

תיקייה זו מחזיקה קבצי רקע שנטענים אוטומטית לכל מי שנכנס ל-Virmeet לראשונה —
לצד הפרסונות וסוגי הפגישות שב-`public/seed/`.

## איך מוסיפים קובץ רקע לפרסונה

1. העלו את הקובץ לתיקייה הזו (`public/seed/files/`) דרך ממשק ה-GitHub — כפתור
   "Add file" → "Upload files" בעמוד התיקייה, או `git add` + commit + push.
   סוגי קבצים נתמכים: `.txt`, `.md`, `.csv`, `.json`, `.pdf`, `.docx`.
2. פתחו את קובץ ה-JSON של הפרסונה תחת `public/seed/personas/<id>.json` והוסיפו
   את שם הקובץ למערך `files`, לדוגמה:

   ```json
   "files": ["files/incident-log-2024.pdf"]
   ```

   הנתיב הוא **יחסי ל-`public/seed/`** — לא כולל את "files/" הקודם אם הקובץ לא
   שם, ולא מתחיל ב-`/`.
3. עשו commit ו-push. ה-build ב-GitHub Actions ירוץ אוטומטית, ייצור מחדש את
   `manifest.json`, ויפרוס את האתר. תוך דקות הקובץ יופיע אצל הפרסונה עם טקסט
   מחולץ ממנו.

## הערות

- קובץ שגדול מ-10MB לא ייטען בדפדפן (אותה מגבלה כמו קבצים שמעלים דרך הממשק).
- אם חילוץ הטקסט נכשל (למשל PDF סרוק בלי שכבת טקסט) — הפרסונה עדיין תיטען,
  עם הודעת שגיאה בעברית ליד הקובץ הזה, כדי שלא יפיל את כל האתר.
- אין למחוק את הקובץ הזה (README.md) — סקריפט בניית ה-manifest מדלג עליו
  במפורש.
